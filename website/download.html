Instalar um nó

Cada nó valida todos os blocos, guarda o histórico, repassa transações e — se você quiser — minera para o seu endereço. Quanto mais nós independentes, mais segura e descentralizada fica a rede. Primeira vez? Comece pelo guia Seja um validador em 1 minuto.

SistemaLinuxx86_64 ou aarch64 (systemd)
CPU1–2 vCPU2+ recomendado para minerar
Memória2–4 GB16 MiB por thread de mineração; swap de 1 GB criado se faltar
Disco / rede5 GB+≈ 430 bytes por transação · porta 7333/tcp aberta

1. Instalação em um comando

Sem nenhuma pergunta — instala, cria a carteira de recompensas e já começa a validar e minerar. Leva cerca de 1 minuto (10–30 minutos se precisar compilar do código-fonte):

curl -fsSL https://the-coin.cloud/install.sh | sudo bash -s -- --yes

Prefere escolher a senha da carteira ou usar um endereço que já tem? Rode sem --yes e responda ao menu:

curl -fsSL https://the-coin.cloud/install.sh | sudo bash

O que o instalador faz

  • Verifica o sistema: Linux x86_64/aarch64 com systemd, memória, disco e se o relógio está sincronizado; oferece criar 1 GB de swap em máquinas com menos de 2 GB de RAM.
  • Baixa os binários thecoind, thecoin-wallet e tccl e confere o checksum SHA-256 antes de instalar (sem binário para a arquitetura, compila do código-fonte).
  • Cria o usuário de sistema thecoin, o diretório de dados /var/lib/thecoin e /etc/thecoin/thecoind.toml.
  • Cria a carteira que recebe as recompensas e mostra as 24 palavras de recuperação no final (anote no papel!).
  • Registra o serviço thecoind (isolado, prioridade baixa), abre a porta P2P no ufw se estiver ativo e inicia o nó.
  • Instala o comando thecoin para acompanhar e administrar o nó. Rodar de novo atualiza e mantém configuração e carteira.

Prefere ler antes de executar? curl -fsSLO https://the-coin.cloud/install.sh && less install.sh && sudo bash install.sh --yes

Opções do instalador

--yes, -y                   não pergunta nada (cria a carteira automaticamente)
--miner-address tc1...      minerar para um endereço que você já tem
--no-mine                   só validar e repassar blocos, sem minerar
--network mainnet|testnet   rede (padrão: mainnet)
--threads N                 threads de mineração (0 = núcleos − 1)
--public-api                expor a API em 0.0.0.0 (só para nós que servem o site)
--version X.Y.Z             instalar uma versão específica (padrão: latest)
--from-source               compilar a partir do código-fonte

As mesmas opções funcionam como variáveis de ambiente: THECOIN_NETWORK, THECOIN_MINER_ADDRESS, THECOIN_NO_MINE=1, THECOIN_THREADS, THECOIN_VERSION, THECOIN_FROM_SOURCE=1, THECOIN_PUBLIC_API=1.

Exemplo: curl -fsSL https://the-coin.cloud/install.sh | sudo bash -s -- --yes --network testnet

2. Acompanhar o nó

thecoin status            # serviço, altura, peers, mineração e saldo
thecoin logs              # logs em tempo real (Ctrl+C para sair)
thecoin balance           # saldo da carteira de recompensas
thecoin address           # seu endereço de mineração
sudo thecoin mnemonic     # mostrar de novo as palavras de recuperação
sudo thecoin restart      # reiniciar após mudar a configuração
thecoin signals           # propostas abertas e as que seus blocos apoiam
sudo thecoin signal <id>   # apoiar uma proposta de governança
sudo thecoin unsignal <id> # retirar o apoio
sudo thecoin update       # atualizar para a versão mais recente
thecoin version           # versões instaladas

A API do nó escuta apenas em 127.0.0.1 por padrão. A configuração completa (threads de mineração, modo pruned, índice de endereços, peers, sinalização de governança) está em /etc/thecoin/thecoind.toml; veja OPERATIONS.md e o guia Seja um validador.

3. Carteira — início rápido

# criar carteira (anote as 24 palavras em papel, offline!)
thecoin-wallet create

# seu endereço para receber / minerar
thecoin-wallet address
thecoin-wallet address --new --label "loja"

# saldo (disponível, travado em votos, recompensas em cooldown)
thecoin-wallet balance

# enviar 12,5 TCN com uma mensagem (prioridade padrão: normal)
thecoin-wallet send tc1qexemplo... 12.5 --memo "Pedido 42"

# com pressa? ou sem pressa?
thecoin-wallet send tc1qexemplo... 12.5 --priority urgent
thecoin-wallet send tc1qexemplo... 12.5 --priority low --replaceable
thecoin-wallet bump-fee <txid>      # só para transações --replaceable

# taxas agora, confirmações recomendadas e alertas de gasto duplo
thecoin-wallet fees
thecoin-wallet confirmations 250
thecoin-wallet alerts

# cobrar: gera uma URI de pagamento (vire um QR code)
thecoin-wallet request 3.5 --memo "Café" --label "Minha Loja"

# pagar uma URI recebida
thecoin-wallet pay "thecoin:tc1qexemplo...?amount=3.5&memo=Caf%C3%A9"

# histórico
thecoin-wallet history

Os valores na linha de comando usam ponto como separador decimal. A carteira conversa com o nó local (http://127.0.0.1:7334); use --node para apontar para outro nó. Contratos de pagamento nativos e contratos TCCL: thecoin-wallet contract --help; pagamentos privados: thecoin-wallet privacy --help.

4. Contratos inteligentes (TCCL)

tccl check contador.tccl                         # confere o contrato
tccl run contador.tccl deploy                    # simula localmente, sem gastar nada
thecoin-wallet contract deploy contador.tccl     # publica na rede
thecoin-wallet contract invoke tc1... incrementar 5
thecoin-wallet contract view tc1... valor        # consulta grátis

Instalação manual

Binários prontos

Baixe o pacote da sua arquitetura em GitHub Releases ou em the-coin.cloud/releases, confira o SHA-256 e extraia:

sha256sum -c thecoin-x86_64-unknown-linux-musl.tar.gz.sha256
tar xzf thecoin-x86_64-unknown-linux-musl.tar.gz
sudo install -m 0755 thecoin/thecoind thecoin/thecoin-wallet thecoin/tccl /usr/local/bin/
thecoin-wallet create
thecoind --miner-address "$(thecoin-wallet address)"

Para ARM64 use thecoin-aarch64-unknown-linux-musl.tar.gz.

Compilar do código-fonte

Requer Rust estável (rustup.rs) e um compilador C.

git clone https://github.com/LucasBolla94/thecoin
cd thecoin
cargo build --release -p thecoin-node -p thecoin-wallet -p tccl
./target/release/thecoind params
./target/release/thecoind --miner-address tc1q...

Em máquinas com pouca RAM, adicione swap ou use cargo build --release -j1.

Espaço em disco

Cada transação ocupa ≈ 430 bytes com o índice de endereços (padrão) e ≈ 350 bytes sem ele — 1 milhão de transações ≈ 430 MB. Para economizar, use prune = true e/ou address_index = false na seção [storage] do thecoind.toml (ou thecoind --prune).

Testar sem gastar nada

Use a testnet (--network testnet, endereços tct1…, portas 17333/17334) ou uma rede local regtest (--network regtest, PoW trivial, ideal para desenvolvimento). Para contratos, o simulador tccl run não precisa de nó nenhum.

Desinstalar

sudo thecoin uninstall            # remove o nó (mantém dados da blockchain e configuração)
sudo thecoin uninstall --purge    # remove também os dados e a configuração
# sem o comando thecoin:
curl -fsSL https://the-coin.cloud/uninstall.sh | sudo bash

Os arquivos da carteira (~/.thecoin/wallet-*.json e a senha gerada pelo instalador) nunca são apagados pelo desinstalador.

Antes de apagar dados, faça backup das palavras de recuperação da carteira. O diretório de dados do nó pode ser apagado com segurança — o histórico é baixado de novo da rede.
