Instalar um nó

Cada nó valida todos os blocos, guarda o histórico, repassa transações e — se você quiser — minera para o seu endereço. Quanto mais nós independentes, mais segura e descentralizada fica a rede.

SistemaLinuxx86_64 ou aarch64 (systemd)
CPU1 vCPU2+ recomendado para minerar
Memória1 GB16 MiB por thread de mineração
Disco / rede5 GBporta 7333/tcp aberta

1. Instalação em um comando

curl -fsSL https://the-coin.cloud/install.sh | sudo bash

O que o instalador faz

  • Detecta a arquitetura e baixa os binários thecoind e thecoin-wallet da versão mais recente.
  • Confere o checksum SHA-256 antes de instalar em /usr/local/bin.
  • Cria o usuário de sistema thecoin, o diretório de dados e o arquivo de configuração thecoind.toml.
  • Pede o seu endereço de mineração (ou cria uma carteira nova e mostra as 24 palavras de recuperação).
  • Registra o serviço systemd thecoind com prioridade baixa e limites de memória, abre a porta 7333 no firewall (se o ufw estiver ativo) e inicia o nó.

Prefere ler antes de executar? curl -fsSLO https://the-coin.cloud/install.sh && less install.sh && sudo bash install.sh

2. Acompanhar o nó

sudo systemctl status thecoind          # estado do serviço
sudo journalctl -u thecoind -f          # logs em tempo real
curl -s http://127.0.0.1:7334/api/v1/status   # altura, peers, hashrate
curl -s http://127.0.0.1:7334/api/v1/mining   # hashrate local e blocos encontrados
sudo systemctl restart thecoind         # reiniciar após mudar a configuração

A API do nó escuta apenas em 127.0.0.1 por padrão. A configuração completa (threads de mineração, modo pruned, peers, sinalização de governança) está em thecoind.toml; veja OPERATIONS.md.

3. Carteira — início rápido

# criar carteira (anote as 24 palavras em papel, offline!)
thecoin-wallet create

# seu endereço para receber / minerar
thecoin-wallet address
thecoin-wallet address --new --label "loja"

# saldo (disponível, travado em votos, recompensas maturando)
thecoin-wallet balance

# enviar 12,5 TCN com uma mensagem
thecoin-wallet send tc1qexemplo... 12.5 --memo "Pedido 42"

# cobrar: gera uma URI de pagamento (vire um QR code)
thecoin-wallet request 3.5 --memo "Café" --label "Minha Loja"

# pagar uma URI recebida
thecoin-wallet pay "thecoin:tc1qexemplo...?amount=3.5&memo=Caf%C3%A9"

# histórico
thecoin-wallet history

Os valores na linha de comando usam ponto como separador decimal. A carteira conversa com o nó local (http://127.0.0.1:7334); use --node para apontar para outro nó. Contratos de pagamento: thecoin-wallet contract --help.

Instalação manual

Binários prontos

Baixe o pacote da sua arquitetura em GitHub Releases ou em the-coin.cloud/releases, confira o SHA-256 e extraia:

sha256sum -c SHA256SUMS
tar xzf thecoin-*-linux-x86_64.tar.gz
sudo install -m 0755 thecoind thecoin-wallet /usr/local/bin/
thecoind init --miner-address tc1q...
thecoind

Compilar do código-fonte

Requer Rust estável (rustup.rs) e um compilador C.

git clone https://github.com/the-coin-cloud/thecoin
cd thecoin
cargo build --release
./target/release/thecoind params
./target/release/thecoind --miner-address tc1q...

Em máquinas com pouca RAM, adicione swap ou use cargo build --release -j1.

Testar sem gastar nada

Use a testnet (--network testnet, endereços tct1…, portas 17333/17334) ou uma rede local regtest (--network regtest, PoW trivial, ideal para desenvolvimento).

Desinstalar

curl -fsSL https://the-coin.cloud/uninstall.sh | sudo bash
# ou manualmente:
sudo systemctl disable --now thecoind
sudo rm /etc/systemd/system/thecoind.service /usr/local/bin/thecoind /usr/local/bin/thecoin-wallet
Antes de apagar dados, faça backup das palavras de recuperação da carteira. O diretório de dados do nó pode ser apagado com segurança — o histórico é baixado de novo da rede.
