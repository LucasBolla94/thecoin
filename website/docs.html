API REST em resumo

Todo nó expõe a API em http://127.0.0.1:7334/api/v1 (mainnet). O site usa https://the-coin.cloud/api/v1, que encaminha para os nós seed. Respostas em JSON; valores em motes (1 TCN = 100.000.000 motes, inteiros); hashes em hexadecimal; endereços em bech32m. Erros retornam {"error": "..."} com status HTTP 4xx/5xx.

MétodoCaminhoDescrição
GET/statusAltura, tip, dificuldade, hashrate, peers, mempool, oferta e parâmetros atuais
GET/supplyOferta máxima, emitida, queimada, circulante, recompensa e próximo halving
GET/feesTaxa mínima e sugerida por byte
GET/blocks?limit=20&before=HResumo dos blocos mais recentes (paginação por altura)
GET/block/{altura|hash}Bloco completo com transações
GET/tx/{txid}Transação confirmada ou no mempool
POST/txEnvia transação assinada: {"tx": "<hex borsh>"} → {"txid": "..."}
GET/address/{endereço}Saldo, disponível, travado, maturando, nonce e próximo nonce
GET/address/{endereço}/txs?limit=25&cursor=H:PHistórico do endereço (mais recente primeiro)
GET/contract/{id}Estado de um contrato de pagamento ativo
GET/governance/proposalsTodas as propostas com apuração e projeções
GET/governance/proposal/{id}Uma proposta
GET/governance/paramsParâmetros atuais e limites
GET/mempoolContagem, bytes e transações de maior taxa
GET/peersPeers conectados ao nó
GET/miningMinerador local: threads, hashrate, blocos encontrados

Exemplos

curl -s https://the-coin.cloud/api/v1/status
curl -s https://the-coin.cloud/api/v1/block/1000
curl -s https://the-coin.cloud/api/v1/address/tc1q...
curl -s -X POST https://the-coin.cloud/api/v1/tx \
     -H 'content-type: application/json' \
     -d '{"tx":"0100..."}'

Padrões usados

Serialização canônicaBorsh (inteiros little-endian, vetores com prefixo u32)
HashBLAKE3 com separação de domínio "TheCoin:" || tag || 0x00 || dados
AssinaturasEd25519 (RFC 8032), verificação estrita
Endereçosbech32m (BIP-350): tc1 mainnet, tct1 testnet, tcr1 regtest
Carteiras HDBIP-39 + SLIP-0010, caminho m/44'/7333'/conta'/0'/índice'
KeystoreArgon2id + ChaCha20-Poly1305
Proof of workCoinHash = Argon2id (16 MiB, t=1, p=1) sobre o cabeçalho de 180 bytes
DificuldadeLWMA-1, janela de 60 blocos, alvo de 60 s
HTLCSHA-256 (compatível com Bitcoin/Lightning para swaps atômicos)
